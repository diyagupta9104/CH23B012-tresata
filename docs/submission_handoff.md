# Submission handoff

## Required materials

1. Written brief, maximum four pages.
2. One-page AI-use appendix, personalized with the candidate’s real prompts, corrections, original decisions, and a point they can defend without tools.
3. Actual AI conversation export or archive, if requested by the submission form.

## Optional prototype

The repository can be shared as the optional prototype link. It contains the README, synthetic input documents, repeatable examples, observed evaluation results, and local run instructions.

## Final checks

- Confirm the written brief is no longer than four pages.
- Remove draft placeholders from the AI-use appendix.
- Attach the actual conversation export; do not invent missing turns.
- Use only synthetic or public data.
- Verify that the shared repository is publicly accessible before submitting its link.
