# AI-use log for the finance assignment

This archive documents how the prototype and submission materials were developed.

The archive contains no private financial data. The prototype uses synthetic suppliers, purchase orders, receipts, credits, and invoices.

Files:

- `conversation_reconstruction.md` — user questions, AI-assisted work, and the resulting decisions.
- `architecture_and_edge_cases.md` — the critical design questions and the edge cases deliberately tested.
- `evidence_index.md` — repository files supporting the claims in this log.
